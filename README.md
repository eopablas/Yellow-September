💛 Setembro Amarelo — Landing Page Informativa

Landing page informativa desenvolvida com o objetivo de conscientizar, informar e incentivar o diálogo sobre saúde mental e prevenção do suicídio, fazendo parte das ações de conscientização do Setembro Amarelo.

O projeto apresenta informações de forma acessível e visualmente agradável, buscando contribuir para a disseminação de conhecimento e para a valorização da vida.

Importante: este projeto possui caráter exclusivamente informativo e educacional. Em situações de sofrimento emocional ou risco, procure ajuda profissional ou os serviços de emergência e apoio disponíveis em sua região.

📌 Sobre o projeto

O Setembro Amarelo é uma campanha de conscientização relacionada à prevenção do suicídio e à promoção do cuidado com a saúde mental.

A landing page foi criada para reunir conteúdos introdutórios sobre o tema em um único espaço, utilizando uma interface simples, responsiva e acessível.

🎯 Objetivos

Promover a conscientização sobre saúde mental.

Incentivar o diálogo sobre sentimentos e sofrimento emocional.

Combater preconceitos relacionados à busca por ajuda.

Apresentar informações e recursos de apoio.

Desenvolver uma experiência web responsiva e acessível.

Praticar o desenvolvimento front-end utilizando tecnologias modernas.

🖥️ Tecnologias utilizadas

O projeto utiliza as seguintes tecnologias:

HTML5 — estruturação semântica das páginas.

CSS3 — estilização e ajustes visuais.

JavaScript — interatividade e comportamento dinâmico.

Tailwind CSS — framework CSS utilizado para construção da interface responsiva.

✨ Funcionalidades

A landing page poderá contar com recursos como:

🏠 Seção inicial com apresentação da campanha.

💛 Sobre o Setembro Amarelo com informações sobre a campanha.

🧠 Informações sobre saúde mental.

💬 Seção de conscientização para incentivar o diálogo.

🤝 Orientações sobre como oferecer apoio a alguém que esteja passando por dificuldades.

📞 Recursos de ajuda com contatos e serviços relevantes.

📱 Design responsivo para computadores, tablets e smartphones.

🌙 Interações em JavaScript, como menus, animações e elementos expansíveis.

🎨 Design

A identidade visual utiliza o amarelo como uma das principais cores da interface, associado à campanha Setembro Amarelo.

A proposta visual busca transmitir:

Acolhimento;

Esperança;

Clareza;

Empatia;

Acessibilidade.

O layout foi pensado seguindo princípios de design responsivo, permitindo que o conteúdo seja apresentado adequadamente em diferentes tamanhos de tela.]

📱 Responsividade

A interface será desenvolvida seguindo uma abordagem mobile-first, utilizando os recursos responsivos do Tailwind CSS.

O layout deve funcionar em:

📱 Smartphones;

📲 Tablets;

💻 Notebooks;

🖥️ Monitores de diferentes resoluções.

📚 Conteúdo e fontes

As informações apresentadas na landing page devem ser baseadas em fontes confiáveis, especialmente órgãos públicos, instituições de saúde e organizações reconhecidas na área de saúde mental.

Entre as possíveis fontes de referência estão:

Ministério da Saúde;

Organização Mundial da Saúde (OMS);

Centro de Valorização da Vida (CVV);

Organização Pan-Americana da Saúde (OPAS).

As fontes utilizadas no conteúdo devem ser apresentadas de maneira clara na própria página ou em uma seção específica de referências.

💛 Mensagem final

Falar sobre saúde mental é uma forma de cuidado.

Este projeto busca contribuir para a conscientização e para a disseminação de informações responsáveis sobre o Setembro Amarelo.

Você não precisa enfrentar momentos difíceis sozinho(a). Procure apoio de pessoas de confiança e de profissionais ou serviços especializados quando necessário.
